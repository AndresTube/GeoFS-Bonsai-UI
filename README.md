# GeoFS Bonsai UI
A premium, monochromatic MSFS-inspired HUD for GeoFS. 

Designed for pilots who want a clean, professional interface without the clutter of the default UI.

## Features
- **MSFS Glassmorphism**: Stunning blur effects and sleek monochromatic typography.
- **Precision Instruments**:
    - **Airspeed & Altitude Tapes**: Smoothly animated vertical tapes for primary flight data.
    - **Dynamic Heading**: High-contrast heading readout with MSFS-style box compass.
- **Aircraft State Tracking**:
    - **Throttle & Reverse**: Live power levels with dedicated reverse thrust indicators.
    - **Flaps & Spoilers**: Interactive visual indicators for flight control surfaces.
    - **Gear & Brakes**: Clear, status-coded panels for gear position and ground braking.
- **Smart Interface Logic**:
    - **Auto-Hide Menus**: HUD elements intelligently fade out when official GeoFS menus are open to prevent overlap.
    - **Clean Bottom Bar**: Full compatibility with external addons like Livery Selector and Jetbridge.
    - **Fixed Playback Slider**: Detached and fixed at the bottom center to stay out of the way of your flight data.
- **Integrated Controls**: Seamlessly styled Radio, Autopilot, and Chat panels.
- **Minimap NAV Enhanced**: Automatically enables navigation layers on the map for easier VFR/IFR flight.

## Installation
1. Install [Tampermonkey](https://www.tampermonkey.net/) in your browser.
2. Download or copy the contents of [geofs-bonsai-ui.user.js](geofs-bonsai-ui.user.js).
3. Create a new script in Tampermonkey and paste the code.
4. Reload [GeoFS](https://www.geo-fs.com/geofs.php).
