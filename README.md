# GeoFS Bonsai UI
a simple but beautiful ui for GeoFS 
with a monochromatic clean MSFS-inspired theme

## Features
Includes:
- Altitude
- Airspeed
- Throttle
- Flaps (not working good at all)
- Spoiilers
- Bottom bar (compatibility with another addons like Livery selector and jetbridge)
- Autopilot
- Radio
- Chat
- Minimap NAV

## Install

1. Install [Tampermonkey](https://www.tampermonkey.net/) in your browser.
2. Open `geofs-bonsai-ui.user.js` and paste it into a new userscript.
3. Reload [geo-fs.com](https://www.geo-fs.com/geofs.php).
